# awesome-gpu-x

Small, focused models that run locally in the browser with WebGPU. This list collects projects that use the GPU for practical inference without shipping a large machine-learning runtime.

## Projects

- [gpu-cron](https://github.com/manuschillerdev/gpu-cron) — Turns English recurring schedules into cron expressions and timezone-aware calendar previews with a 35,783-parameter model trained on MLX. [Try it](https://gpu-cron.vercel.app/).
- [gpu-lexer](https://github.com/vercel-labs/gpu-lexer) — Highlights source code with a small, language-agnostic neural lexer running on WebGPU. [Try it](https://gpu-lexer.vercel.app/).
- [gpu-time](https://github.com/arikchakma/gpu-time) — Parses English time expressions into dates, ranges, and recurrence rules with a small model that supports WebGPU.

Contributions are welcome. Please suggest projects that keep inference local, models small, and browser runtimes lean.
